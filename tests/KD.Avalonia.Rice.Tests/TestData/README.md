# Markdown specification examples

`commonmark-examples.json` and `gfm-examples.json` contain selected examples
adapted from the CommonMark specification by John MacFarlane and the GitHub
Flavored Markdown specification by GitHub, Inc., based on CommonMark.

Changes in KD.Avalonia.Rice: examples were selected, converted into JSON
input/expected-HTML pairs and supplemented with project-specific cases.
